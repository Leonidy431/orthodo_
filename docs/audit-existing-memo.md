## Предложенные исправления без переписывания источника

1. Пока источники не сверены, не представлять молитвы и обычаи из исходного файла как подтверждённое пересечение. Текущая консервативная версия результатов находится в `docs/common-prayers-and-customs.md`.
2. Для любых будущих подтверждений добавить точную цитату/раздел и ссылку для каждой из трёх церквей; если свидетельство есть только для одной, прямо помечать материал как традиционно-специфический, а не общий.
3. Описания книг, изданий, наличия полного текста и прав заменить на проверенные библиографические сведения. Не скачивать и не публиковать текст при неясном разрешении.
4. Сохранить все различия редакций и локальных практик; не объявлять церкви одной юрисдикцией. В частности, не объявлять *I Confess with Faith* общим циклом без доказательства.

Ни одна из этих оговорок не является выводом о том, что содержание памятки фактически ошибочно: доступные доказательства оказались недостаточны для подтверждения или опровержения.

Git clone: **0**; HTTPS-загрузок полных книжных текстов: **0**.
Доступ по HTTPS к GitHub и чтение метаданных через MCP не названы клонированием.
Книжные SHA-256, ревизии импортированных книг, LICENSE/NOTICE для них отсутствуют,
потому что таких импортов нет, а не потому что ими можно пренебречь.
Общий [NOTICE](../../sources/third-attempt/NOTICE) не является лицензией книги.

SHA-256 локальных результатов хранятся в
[SHA256SUMS](../../data/third-attempt/SHA256SUMS); они проверяют артефакты задания,
а не недоступные первичные книги. Генератор не скачивает данные и не запускает
чужой код. Новые зависимости, hooks, submodules и Git LFS не используются.

При продолжении:

1. Прочитать титульный/издательский лист, указать редакцию и переводчика.
2. Проверить весь нужный текст и конкретную лицензию/разрешение правообладателя.
3. Проверить применимость условий к публичной публикации в GitHub.
4. Только после этого получить разрешённый файл по HTTPS либо клонировать
   реальный Git-источник в изолированную временную папку без исполнения кода.
5. Сохранить URL, фактический commit SHA для Git, дату, SHA-256, атрибуцию,
   LICENSE/NOTICE и полный журнал преобразования.
6. Опубликовать отдельный содержательный коммит после каждого разрешённого импорта.

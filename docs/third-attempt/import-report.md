## Проверки

Сборщик работает стандартной библиотекой Python, по умолчанию — dry-run.
Проверены ZIP CRC, разбор всех XML-частей, наличие `word/document.xml`,
последовательное сохранение всего исходного текста, по три ячейки в каждой
строке, равная ширина колонок, повтор заголовка, A4 landscape и поле PAGE.
При проверке редактором исправлен порядок используемых OOXML-свойств.
Полная проверка OOXML-схемой не выполнялась.

Отрицательные случаи: неверный титул, лишняя и пустая ячейка отклоняются;
длинный греческий текст сохраняется без усечения в XML. Это не доказывает
визуально корректную пагинацию. Внешний рендерер и визуальный просмотр недоступны.
DejaVu Sans указан, но не встроен. Проверка шрифта, переносов и полей
в приложении Word остаётся открытой.

Встроенной тестовой инфраструктуры в исходном репозитории нет; новая
не добавлялась. `git diff --check`, структурные проверки и контрольные суммы
используются вместо заявления о несуществующем тестовом наборе.
Секреты сканируются перед каждым содержательным коммитом.

CodeQL Python сообщил 0 alerts. Компонент автоматического Code Review
не запустился из-за отсутствующей модели; это явно зафиксировано, не
названо успешной проверкой. Дополнительный отдельный read-only reviewer
существенных проблем не обнаружил. Подробнее: [редакторский отчёт](editorial-review.md).

## Почему работа не завершена

Прямые церковные источники не открываются из среды: ошибки DNS; встроенный
поиск работает, но поисковые изложения местами смешивают документы.
Поэтому из них не скопированы точные молитвы, цитаты или готовые правила.
Статус второго задания не выводится из прежнего `user_cancelled`.
Проверено собственное окружение, не переписан отчёт первого процесса.

Продолжение требует доступного первичного источника каждой традиции,
проверки редакций/юрисдикций и прав, затем реального подтверждённого
трёхъязычного элемента. Только после этого можно заполнять молитвенный
минимум и общие обычаи и обновлять монографию вместо редакционного макета.

## Доказательства и фильтры

Статусы: направление поиска → обнаруженный кандидат → проверенная книга →
отобранная книга → разрешённое получение → импорт → преобразование → публикация.
Ни один следующий статус не следует автоматически из предыдущего.

F1 существование; F2 самостоятельная книга/брошюра; F3 тема и аудитория;
F4 EL/EN/BG; F5 установленное происхождение. Непроверенный фильтр — `null`,
не ложь и не подтверждение. Пока все пять не подтверждены, кандидат не считается
проверенной книгой. Сведения только из поиска хранятся как предварительные:
они не подтверждают полноту, редакцию, конкретную цитату или права.

P1 право на конкретный текст; P2 атрибуция/лицензия; P3 отсутствие обхода.
Только после прохождения P1–P3 допустим импорт. Неизвестное право не получает
оценку 0 и не подменяется лицензией программы. В этом запуске разрешённых
импортов нет, поэтому импортёр не создавался.

Уровни 3–5 у параметров 3–5 требуют отдельного свидетельства нужной традиции;
общее православное происхождение его не заменяет. Высокий балл 11 сам по себе
не разрешает импорт: например, некоммерческое условие требует отдельной проверки
совместимости с публичным репозиторием.

Баллы: `sum(известных)/(5 × число известных) × 100`.
Полнота: `число известных/12 × 100`. При нуле известных балл — Н/Д,
полнота — 0%; деление на ноль не выполняется.
В основном рейтинге нужны F1–F5 и полнота ≥75%; сортировка по баллу,
затем полноте. Никаких числовых оценок по одним поисковым пересказам
в этой попытке не присвоено. Каталог сохраняет все 12 позиций как Н/Д.

Буквальное совпадение проверяется внутри одного языка и конкретной редакции.
Между EL/EN/BG проверяется соответствие смысла, а не буквальное тождество.
Англоязычные диаспорные источники армянской традиции не считаются
свидетельствами практики всех общин непосредственно в Армении.

## Поиск и дедупликация

Примеры реально использованных запросов:

- EL: `site:churchofcyprus.org.cy προσευχή Πάτερ ημών ναό ενδυμασία προσευχητάριο`.
- EN: `site:armenianprelacy.org "NEW EDITION" "IN FAITH I CONFESS" 2022`.
- BG: `site:bg-patriarshia.bg "Молитвеник" "Синодално"`.
- GitHub repository search: `orthodox prayer book`.
- GitHub code search: `"In Faith I Confess"`; найденный корпус не принят за церковную книгу.

Форматы, зеркала и главы группируются по произведению, автору, языку и редакции.
Без файлов нельзя утверждать совпадение SHA-256. Болгарские веб-главы пока не
отождествлены побайтово с печатным изданием и не посчитаны новыми книгами.
Чикагская страница молитв, кипрская утренняя молитва и каталоги — отдельные
вспомогательные источники, не самостоятельные книги.

## Воспроизводимость

Нет установок зависимостей, клонирований, запусков чужого кода или обхода
сетевых ограничений. Проверка `git ls-remote` не считается клонированием.
GitHub MCP использовался для чтения метаданных двух проектов; лицензия
приложения не стала разрешением на содержащиеся в нём молитвы.

Сборка макета (из любой рабочей папки):

```sh
python /home/runner/work/orthodo_/orthodo_/scripts/build_word_third_attempt.py
python /home/runner/work/orthodo_/orthodo_/scripts/build_word_third_attempt.py --write
python /home/runner/work/orthodo_/orthodo_/scripts/build_word_third_attempt.py --check
cd /home/runner/work/orthodo_/orthodo_
sha256sum --check data/third-attempt/SHA256SUMS
```

Первая команда — dry-run без записи. Исходник и результат по умолчанию вычисляются
от расположения сборщика; пути можно явно задать через `--source` и `--output`.
Новая тестовая инфраструктура не добавлена: в исходном репозитории её нет.
Вместо этого сборщик проверяет свои выходные инварианты; отрицательные случаи
проверены стандартным Python без сохранения временных файлов в репозитории.

## Правило допуска

Перед хранением полного текста необходимо установить правообладателя и разрешение на конкретные действия: копирование в репозиторий, преобразование в Markdown и публичное распространение. Зафиксировать точный URL лицензии/разрешения, версию или дату редакции текста, дату проверки, ограничения атрибуции и неизменности. Права на веб-страницу, программный код репозитория, обложку или PDF не считать автоматически правами на вложенную книгу или перевод.

Если разрешение не подтверждено, сохраняются только проверенные библиографические метаданные и ссылка; содержимое не копируется. Если источник окажется подходящим Git-репозиторием, применять `git clone --depth 1` лишь после проверки прав на конкретные тексты, не запускать его код/hooks/install scripts и переносить только разрешённые нужные файлы и LICENSE/NOTICE. Записывать commit SHA. Для разрешённой загрузки вне Git — URL и SHA-256; такую загрузку не называть `git clone`. Большие бинарные файлы не добавлять.

В переданных восьми стартовых ссылках лицензии/условия по конкретным текстам не удалось проверить: DNS-запросы из среды завершились ошибкой. Поэтому ни одна ссылка не имеет статуса разрешённого источника в `sources-manifest.json`.

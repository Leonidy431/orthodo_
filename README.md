# orthodo_

Исследовательский реестр молитвенных книг и материалов о поведении в храме для греко-православных общин Кипра, Армянской апостольской церкви и Болгарской православной церкви. Эти церкви рассматриваются раздельно, а не как одна юрисдикция.

## Фактический статус исследования

- Проверено доступных уникальных книг/самостоятельных брошюр: **0**.
- Оценено по 12 параметрам и включено в рейтинг: **0**.
- Разрешено к импорту и публичному распространению полных текстов: **0**.
- Стартовых ссылок проверено сетевым запросом: **8**; все запросы завершились ошибкой DNS в этой среде. Это не доказывает недоступность сайтов для других пользователей.
- Выполнено `git clone`: **0**; скачано файлов: **0**; импортировано текстов: **0**.

Числа 999 и 99 — цели исследования, а не достигнутые результаты. В непроверенные источники и исходный файл-памятку не вносились предположения как подтверждённые факты.
